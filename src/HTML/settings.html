Help and Feedback

Where is my data saved?

Signed in, everything you log is saved to your account and shows on every device you log in on. Signed out, it stays in this browser only; creating an account keeps it. Theme, units and a few preferences are kept per device.

How does command mastery work?

Each command earns levels, from Learning to Mastered, as you log more sessions on more days, in more places and with distractions. Commands page > Command Mastery shows where each one stands.

Why did a command drop a level?

With mastery decay on, a command slips a level after a while without practice; higher levels hold longer, and so do commands that keep scoring well. Practice it to win the level back, or turn decay off on the Commands page.

How do I log a walk by distance?

On the Log page, switch to Exercise and set Track by to Distance. The unit starts on the one picked under Units above.

How do I log several commands at once?

On the Log page, pick every command you worked on. Each gets its own reps and duration, and each is saved as its own session.
